Labs from the Python programming course in the Data Engineering program at STI. The labs cover Python fundamentals, data processing, object-oriented programming and visualization.

## Labs

| Lab | Description | Topics |
|---|---|---|
| [01 DNA Sequence Analysis](01_lab_dna_sequence_analysis) | Reads raw DNA data, counts letter frequencies per sequence and plots the result | File handling, dictionaries, data cleaning, matplotlib |
| [02 Geometry OOP](02_lab_geometry_oop) | Classes for 2D shapes, planned with UML and built with inheritance | OOP, inheritance, properties, operator overloading, error handling |

Each lab folder has its own README with details and instructions.
